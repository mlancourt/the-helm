LannyAI Mail Attachments

LannyAI Mail Attachments is a private, single-user tool. It runs on its owner's own computer and has no other users, no sign-up and nothing to download.

It does one job: when its owner's personal filing system has already recorded an email as a document worth keeping, the tool asks Gmail for that one message and saves its attachments (a PDF statement or invoice, for example) into the owner's private archive, next to the record of the email.

It uses read-only access to its owner's Gmail account. It cannot send, change, label or delete mail. It does not list or search the mailbox; it only fetches messages the filing system has already named.
